# Cartella Sorgenti (`sources/`)

Metti qui i materiali del tuo corso prima di iniziare la chat con la tua IA:

- **Appunti in PDF** (`.pdf`)
- **Slide del docente** (`.pdf`, `.pptx`)
- **Appunti LaTeX o Markdown** (`.tex`, `.md`, `.txt`)

Puoi organizzare i file liberamente (anche un unico PDF intero o una cartella per lezione).
Poi apri la tua IA (Claude Code, Antigravity, Codex, Cursor, Gemini CLI...) e scrivi:

> *"Iniziamo: guarda cosa c'è in `sources/` e guidami passo passo nella creazione delle videolezioni."*
